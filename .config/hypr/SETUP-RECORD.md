## Rainbow text correction

The physical display showed colored fringes because the existing font stack
forced RGB LCD subpixel antialiasing. A native screenshot contained the same
orange/cyan glyph-edge pixels, while the live output remained SDR sRGB,
XRGB8888, scale 1 over DP-3. This rules out an NVIDIA color-conversion fault.

`fontconfig-hyprland.conf` now includes the normal Arch/user font configuration
and overrides only `rgba=none`. `hyprland.lua` exports that file through
`FONTCONFIG_FILE`, so newly launched Hyprland applications use grayscale AA;

inherit the new session environment.
